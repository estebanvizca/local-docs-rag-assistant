# Sample corpus

The four documents in `documents/` are **original, fictional technical documents**
written specifically for this demo:

| File | Format | Pages |
|------|--------|-------|
| `edge-gateway-operations.md` | Markdown | — |
| `incident-response-runbook.md` | Markdown | — |
| `python-service-checklist.md` | Markdown | — |
| `open-systems-handbook.pdf` | PDF (generated) | 6 |

They are licensed under **Creative Commons Attribution 4.0 International
(CC BY 4.0)**: you may share and adapt them with attribution. They contain no
real company data, customer information, personal data or credentials. Product
names such as "Nimbus" are invented.

The PDF is generated by `tools/build_sample_pdf.py` so its content is auditable
and reproducible:

```bash
python tools/build_sample_pdf.py
```

If you replace the corpus with your own documents, keep only material you have
the right to publish, and update `eval/questions.jsonl` before trusting any
metric.
